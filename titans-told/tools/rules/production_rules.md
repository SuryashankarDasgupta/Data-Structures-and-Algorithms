## 4. Illustrations (Canva, automatic)
VARIETY + QUALITY RULES (owner, 6 Nov 2026: "same footage keeps coming consecutively" and "the quality looks non-HD"): every illustration is used ONCE in the whole video (owner, 6 Nov 2026: "don't use the same visuals twice"), so make about ONE NEW illustration per 6–7 seconds of narration (125–140 for a 14-min video, because shots are now shorter; the visual plan lists them — add subjects if it has fewer). After every batch of up to 10 new images, immediately save a new plain-text file `illustrations – batch NN.md` (the next NN) to the draft's Drive folder (create_file, textContent, contentMimeType text/markdown, disableConversionToGoogleType true) listing that batch's lines. ## 5b. Hero clips (owner decision 12 Nov 2026, after the price test)
**How many:** every long video gets ONE 4-second hero clip in the hook (first ~10 s). Each week (Mon–Sun) exactly ONE video, the week's strongest, also gets a second 4-second clip at its main twist (about 30–40% of the way in, where retention usually dips). The strongest video is the one whose script header says `Twist clip: yes` (the content routine marks one per week); if no script of the week is marked, give it to the first video of the week whose header has a `Twist:` line. Never more than 2 clips per video. Skip the twist clip if this week's logged spend plus 80 would pass ~770, or the cycle total would pass 3,300; skip every clip under the 1,500 balance floor.
**Model (price test 12 Nov 2026: gemini-omni-flash 100, wan-3 100, seedance-2-fast 140 credits per 5 s):** use **gemini-omni-flash or wan-3**, whichever suits the shot better: gemini-omni-flash (video-edit mode, takes our full-resolution illustration, best for keeping fine line detail and for subtle motion: light, rain, smoke, screens) or wan-3 (start frame, better at strong camera moves and larger motion, but the start frame must be a small ≤ 25 KB WebP pasted into the call, so it is slightly softer). Decide BEFORE generating and generate each shot ONCE with one model. **Never use seedance-2-fast.** A 4 s clip costs about 80 credits on either model.
1. **Reuse first.** List the Drive folder "TT clip library" (`1StyShP2xlY7hY8vkZpG11YyFSOi0o6ER`; search_files `parentId = '1StyShP2xlY7hY8vkZpG11YyFSOi0o6ER'`). Every clip is one .mp4 whose file name and Drive `description` say what it shows. If a listed clip fits (same company, product, place or mood), download it (download_file_content) to `work/hero/<hook|twist>.mp4` and skip to step 5.
2. **Source.** Pick the single strongest illustration of the beat (hook: the SHOCK or TENSION line, or the script's `Hero clip:` line; twist: the main twist line): our own art from img4k/, no people's faces in close-up, no text in the image.
3. **Generate (paid: run vidiq_balance first; budget rules in shared facts).** Prompt: "Animate this illustration with gentle cinematic motion: <one concrete motion from the scene>. Keep the exact comic-book illustration style: bold ink outlines, flat cel shading, subtle paper grain, the navy, cream, gold and brown palette. No text, no logos, no new people, no photorealism; do not change faces."
   - **gemini-omni-flash:** `ffmpeg -y -loop 1 -i img4k/sNN.png -t 4 -vf "scale=1280:720,format=yuv420p" -r 24 -c:v libx264 -crf 18 work/hero/src.mp4` → `vidiq_video_upload` with `localFile` = work/hero/src.mp4, run the shell command it returns, take the video URL → `vidiq_generate_video` model gemini-omni-flash, `videoUrls` = [that URL], duration 4, resolution 720p.
   - **wan-3:** `python3 -c "from PIL import Image; Image.open('img4k/sNN.png').convert('RGB').resize((512,288)).save('work/hero/start.webp', quality=50, method=6)"` (must be ≤ 25 KB; lower quality to 45 or width to 480 if not) → `base64 -w0 work/hero/start.webp` → `vidiq_generate_video` model wan-3, `startFrameB64` = that base64 text copied exactly, duration 4, resolution 720p, aspectRatio 16:9.
   Poll `vidiq_job_poll` until done and download the mp4 to `work/hero/<hook|twist>.mp4`. **No re-rolls without the owner's approval.** If the result breaks the style or shows garbled text or faces, or the provider rejects it (credits are refunded), do not retry: use the normal shots there and say so in the record and the Scheduled email.
4. **Library.** Make a library copy under 3 MB (a connector call carries at most ~3.1 MB of file): `ffmpeg -y -i work/hero/<name>.mp4 -an -c:v libx264 -crf 26 -preset slow -pix_fmt yuv420p work/hero/lib.mp4` (raise -crf by 2 until it is < 3,000,000 bytes). Upload it into the "TT clip library" folder with create_file (`base64Content` as a file reference `sha256:<hex>:<absolute path>`, contentMimeType video/mp4, disableConversionToGoogleType true), file name `<brand>_<what it shows>_<YYYY-MM-DD>.mp4`, then set its description with update_file: `date | video | hook or twist | source illustration | model | credits | one-line description`. (The video itself always uses the full-quality clip.)
5. **Edit.** In cues.py put each clip as ONE scene on its line: `("<anchor phrase>", dict(type="clip", clip="hero/hook.mp4"))` (and `hero/twist.mp4`; paths relative to work/, where tt_compose runs; it upscales the clip to the canvas at export). Like every scene it lasts until the next cue's anchor, so anchor the next cue about 3.5–4 s later (max 5.2 s; tt_cues checks it). A clip is exempt from the hook's 2.6 s cut rule, counts as a re-hook, and is used once. Log the video's group in the credit log: `1 clip` or `2 clips`.
