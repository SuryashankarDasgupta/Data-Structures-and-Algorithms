# Titans Told image library (breaking-news lane)
415 of the channel's own illustrations (1920x1080 JPEG), reusable for fast videos.
catalog.json: [{"id", "desc", "from"}]; image file = img/<id>.jpg.
No real-person likenesses (portraits removed). Each image may be used once per video.
Clone only this branch when needed: git clone --depth 1 -b titans-told-library <repo> /tmp/ttlib
